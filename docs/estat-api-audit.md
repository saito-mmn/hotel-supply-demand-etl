# e-Stat API 提供範囲調査

調査日：2026-08-10

## 結論

宿泊旅行統計調査について、e-Stat APIから統計値を直接取得できるデータベース表は確認できたが、v2 MVPの対象である2019～2025年の年確定値は取得できなかった。

そのため、2019～2025年MVPではe-Stat APIを統計値の主経路にせず、e-Statまたは観光庁が配布する年確定値Excelを公式入力とする。APIは提供範囲の確認、旧系列のメタデータ調査、将来の提供状況の再確認に利用する。

## 実施した確認

### 統計表一覧

`getStatsList`で統計コード`00601020`（宿泊旅行統計調査）を検索したところ、32件のデータベース表を取得した。取得した表は対象期間が主に2014～2016年、公開・更新が2019年の系列だった。

主要な候補表：

| 統計表ID | 内容 | APIメタ情報上の対象期間 |
|---|---|---|
| `0003313482` | 都道府県・月別施設数 | 2014～2016年系列 |
| `0003313661` | 都道府県・月・施設タイプ別延べ宿泊者数 | 2014～2016年 |
| `0003313903` | 都道府県・月別客室稼働率 | 2014～2016年系列 |
| `0003314402` | 居住地別延べ宿泊者数 | 2014～2016年系列 |

### 延べ宿泊者数表のメタ情報

統計表ID`0003313661`の`getMetaInfo`で次を確認した。

- 統計名：宿泊旅行統計調査（年確定値）
- 対象期間：2014～2016年
- 表章項目：延べ宿泊者数
- 単位：人泊
- 宿泊施設タイプ：合計、旅館、リゾートホテル、ビジネスホテル、シティホテル、簡易宿所、会社・団体の宿泊所
- 宿泊者区分：延べ宿泊者数、うち外国人延べ宿泊者数
- 地域：全国、47都道府県、運輸局等
- 時間軸：年次、月次

主要分類コード：

| 分類 | コード | 意味 |
|---|---|---|
| `tab` | `110` | 延べ宿泊者数 |
| `cat01` | `100` | 宿泊施設タイプ合計 |
| `cat02` | `100` | 延べ宿泊者数 |
| `cat02` | `110` | うち外国人延べ宿泊者数 |
| `area` | `01000`～`47000` | 47都道府県 |

### MVP対象年の検索

`getStatsList`を統計コード`00601020`と対象年で絞り込んだ結果：

| 対象年 | 結果 |
|---|---|
| 2019 | 該当データなし |
| 2024 | 該当データなし |
| 2025 | 該当データなし |

これはe-Stat上に年確定値Excelが掲載されていないという意味ではない。Excel等のファイル配布と、`getStatsData`で値を取得できるデータベース化された統計表は別である。

## v2への影響

2019～2025年MVPの取得経路を次の順とする。

1. e-Statまたは観光庁の公式年確定値Excel
2. e-Stat APIは統計値の主経路にしない
3. APIで将来対象年が提供された場合は、Excelとの照合後に取得経路の変更を検討する

APIクライアントは削除しない。公式インターフェースの提供範囲を再確認できること、統計表のメタデータと分類コードを調査できること、将来のAPI対応へ拡張できることに価値がある。ただし、READMEでMVPの主取得経路として表示しない。
