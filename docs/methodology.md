# 宿泊市場モニタリングの方法論

## 1. 目的と利用範囲

本分析は、ホテル担保の評価・審査・与信管理において、都道府県単位の宿泊市場変化を一次スクリーニングするためのものである。地域全体の変化と個別ホテル固有の変化を切り分ける前段として使い、担保価値、融資可否、対象ホテルの収益性を直接判定しない。

出力は次の3つを明確に分ける。

- 観測事実：公式統計から計算できる変化
- 解釈上の注意：都道府県統計から断定できない事項
- 次の確認事項：個別ホテル・商圏について追加取得すべきデータ

## 2. 対象データ

- 統計：観光庁「宿泊旅行統計調査」
- 期間：2019～2025年
- 分析対象年：2025年
- 基準年：2019年（コロナ禍前）
- 前年比較：2024年
- 粒度：都道府県×月
- 公表区分：年確定値
- 需要：延べ宿泊者数、日本人延べ宿泊者数、外国人延べ宿泊者数
- 稼働：客室稼働率
- 供給の代理変数：施設数

施設数は客室数ではないため、供給能力を完全には表さない。施設数の増加を「供給過多」と断定せず、需要の伸びとの乖離を追加確認の契機として扱う。

## 3. 集計方法

| 指標 | 定義 |
|---|---|
| 年間延べ宿泊者数 | 12か月の延べ宿泊者数の合計 |
| 年間外国人比率 | 年間外国人延べ宿泊者数 ÷ 年間延べ宿泊者数 |
| 年平均客室稼働率 | 12か月の客室稼働率の単純平均 |
| 年平均施設数 | 12か月の施設数の単純平均 |
| 2019年比 | 対象年の年間延べ宿泊者数 ÷ 2019年の年間延べ宿泊者数 × 100 |
| 需要前年比 | 対象年と前年の年間延べ宿泊者数の変化率 |
| 稼働率前年差 | 対象年平均客室稼働率 − 前年平均客室稼働率 |
| 施設数前年比 | 対象年と前年の年平均施設数の変化率 |
| 需要吸収ギャップ | 需要前年比 − 施設数前年比 |
| 月次変動係数 | 対象年の月次延べ宿泊者数の母標準偏差 ÷ 月平均 |
| 最大月構成比 | 最大月の延べ宿泊者数 ÷ 年間延べ宿泊者数 |

年間外国人比率は月次比率の単純平均ではなく、年間合計同士の比率とする。客室稼働率は稼働客室数などの月別分母を本データモデルに保持していないため単純平均であり、加重平均ではない。

## 4. ウォッチ条件

閾値は[`analysis.toml`](../analysis.toml)で変更できる。初期値は、ポートフォリオ用の説明可能な一次スクリーニング条件であり、統計的に推定した信用リスク閾値ではない。

| 条件 | 初期閾値 | 検知の意味 |
|---|---:|---|
| 2019年需要水準未達 | 2019年比90%未満 | コロナ禍前水準からの回復継続性を確認 |
| 需要の前年比低下 | −5%以下 | 直近年の需要悪化を確認 |
| 稼働率の前年比低下 | −5pt以下 | 需要・供給または稼働環境の変化を確認 |
| 供給増加に対する需要吸収 | 施設数+3%以上、需要吸収ギャップ−5pt以下 | 施設増加に需要増加が追いついているか確認 |
| 外国人需要構成の変化 | 前年差の絶対値10pt以上 | 需要構成変化と特定市場への依存を確認 |
| 外国人需要への集中 | 外国人比率50%以上 | 外部環境変化への感応度を確認 |
| 月次需要の高変動 | 変動係数0.35以上 | 季節性・イベント依存などを確認 |

条件に該当しないことは、対象市場または担保が安全であることを意味しない。

## 5. 市場状態分類

単一の点数や県別順位を作らず、説明可能な状態へ分類する。複数条件に該当する場合は、データ不足、需要悪化、供給吸収、需要・稼働率改善、高変動・需要構成偏重、回復継続性、横ばいの順に優先する。すべての検知理由は分類とは別に保持するため、優先分類によって他の根拠が失われることはない。

## 6. 公表版と前回公表差分

SQLiteの`latest_monthly_demand`と`latest_monthly_supply`は、確定値、第2次速報、第1次速報の順で最新版を選択できる設計である。ただしPhase 2の入力は年確定値のみであり、同一対象期間の複数公表版や差し替え前ファイルを保持していない。そのため「前回公表差分」は現時点では算出不能であり、ゼロとして扱わない。速報値・訂正履歴を追加する段階で実装する。

## 7. 解釈上の制約

- 都道府県値から個別ホテルのADR、RevPAR、GOP、NOIは分からない
- 施設数は客室数・供給客室数の代替ではない
- 施設タイプ、価格帯、商圏、ブランド構成の違いを調整していない
- 災害、イベント、交通、開業・閉館などの要因を統計だけで特定できない
- 2019年単年は比較基準であり、正常値または長期均衡を意味しない
- 閾値付近の差を機械的に重大と判断しない

ウォッチ対象については、対象ホテルのADR・RevPAR・GOP、競合施設の客室数と開閉業、商圏別需要、契約条件、修繕・設備投資などを追加確認する。
