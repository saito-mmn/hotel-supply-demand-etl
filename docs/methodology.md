# 宿泊市場モニタリングの方法論

## 1. 目的

本レポートは、ホテル担保の評価・審査・与信管理において、全国のホテル市況と担保物件所在地の市場推移を確認するための一次スクリーニング資料である。

統計から担保価値や投資判断を自動判定するものではない。客室稼働率、宿泊需要、インバウンド構成、調査対象施設数を比較可能な形へ加工し、個別ホテルのADR、RevPAR、GOP、競合状況などを追加調査するための市場背景を提供する。

## 2. 対象データ

| 区分 | 入力 | 粒度 | 主な用途 |
|---|---|---|---|
| 都道府県 | 観光庁「宿泊旅行統計調査」年確定値Excel | 全国・47都道府県×月 | 全国の地合いと都道府県市場の比較 |
| 市区町村 | e-Stat等で配布される月次第2次速報Excel | 掲載された主な市区町村×月 | 担保物件所在地の市場推移の確認 |

都道府県値は未回収分を含む推計値、市区町村値は公表条件を満たした主な市区町村の実数であり、集計基準が異なる。市区町村値を合計して都道府県値を再構成せず、両者を同一母集団として直接比較しない。

## 3. レポートの比較方法

### 3.1 都道府県

全国レポートでは、公式Excelに掲載された全国客室稼働率の2019年および直近3年の月次推移と、47都道府県の一覧を表示する。全国値は47都道府県の単純平均ではない。年間平均は公式の月次全国値12個の単純平均である。

都道府県一覧では、次の指標を個別にソートできる。

- LTM平均客室稼働率と前年差
- 調査対象施設数と前年比
- LTM外国人延べ宿泊者比率と外国人客数前年比
- Seasonal CV、繁閑レンジ、ピーク月・ボトム月

都道府県Market Sheetは、次の順で表示する。

1. 客室稼働率：2019年を破線の比較基準とし、直近3年を月別に重ねる
2. 延べ宿泊者数：直近3年の月次総需要と、日本人・外国人の年次需要構造を表示する
3. 宿泊施設数：2019年および直近3年の各年12月時点を比較する

### 3.2 市区町村

市区町村一覧は、各自治体の最新掲載月における客室稼働率、延べ宿泊者数、外国人比率、調査対象施設数を表示する。自治体によって最新掲載月と掲載月数が異なるため、同じ時点の横断比較とは限らない。

市区町村Market Sheetは、次の順で表示する。

1. 客室稼働率：2019年を破線の比較基準とし、直近3年を1月～12月の同じ軸に重ねる
2. 延べ宿泊者数：直近3年の月次需要を重ね、比較可能な場合に年次需要構造を表示する
3. 宿泊施設数：2019年および直近3年の12月時点を比較する

年次需要構造は、対象となる直近3年の各年について12か月すべての総数・日本人・外国人宿泊者数が掲載されている場合のみ表示する。施設数の年次グラフは、対象年の12月値が2年分以上ある場合のみ表示する。非掲載月をゼロとして補完せず、月次グラフの線を途切れさせる。

## 4. 指標定義

| 指標 | 定義 |
|---|---|
| LTM | 基準月までの直近12か月 |
| LTM平均客室稼働率 | LTM12か月の客室稼働率の単純平均 |
| 客室稼働率前年差 | 当期LTM平均客室稼働率－前年同期LTM平均客室稼働率 |
| 施設数前年比 | 基準月の調査対象施設数÷前年同月の調査対象施設数－1 |
| 外国人比率 | LTM外国人延べ宿泊者数÷LTM総延べ宿泊者数 |
| 外国人客数前年比 | 当期LTM外国人延べ宿泊者数÷前年同期LTM外国人延べ宿泊者数－1 |
| Seasonal CV | 月次客室稼働率12値の母標準偏差÷年間平均客室稼働率 |
| 繁閑レンジ | 年間の最高月客室稼働率－最低月客室稼働率 |

客室稼働率は月別の客室数分母を保持していないため、年間値やLTM値は単純平均であり加重平均ではない。Seasonal CVと繁閑レンジは市場の良否判定ではなく、年間キャッシュフローの繁閑差を理解するための市場特性として扱う。

2019年はコロナ禍前との比較基準であり、正常値、適正水準、長期均衡を意味しない。

## 5. 欠損値と制度変更

Excelの空欄、`-`、`…`、`...`、`X`、`*`はゼロへ変換せず、SQLiteでは`NULL`として保持する。実績がゼロであることと、非公表・回収基準未達・欠損であることを区別するためである。

市区町村の客室規模別数値は、区分ごとに10施設以上の回答がない場合に非表章となる。2026年1月から施設規模の層化基準が従業者数から客室数へ変更されているため、制度変更をまたぐ客室規模別比較には使用しない。客室規模別レコードはSQLiteに保持するが、現在のMarket Sheetには表示しない。

## 6. 公式Excelの構造に依存する実装と変更リスク

parserは、対象期間の公式Excelで確認した既知の帳票仕様を厳格に読み取る。これは将来も不変であることが保証されたAPI仕様ではない。類似する表を推測して読み続けるより、構造変更時に処理を停止させ、誤った値のDB格納やレポート公開を防ぐ方針である。

### 6.1 都道府県年確定値Excel

現在の実装は次の構造に依存する。

- シート名が`第1表(1月)`、`第4表(1月)`、`第8表(1月)`の形式である
- 第1表の「総数」が調査対象施設数である
- 第4表の「延べ宿泊者数」「うち外国人延べ宿泊者数」が需要指標である
- 第8表の「客室稼働率」が稼働率指標である
- 見出しと調査年月がシート先頭15行以内にある
- 都道府県行のA列が2桁の都道府県コードと都道府県名で始まる
- 全国客室稼働率は、A列に和暦の調査年月が記載された行の「客室稼働率」列にある

特に「A列に調査年月がある行を全国値行とみなす」という条件は帳票配置への依存である。全国値行の位置、日付表記、列見出し、表番号が変わった場合は、原Excelを確認した上で`src/hotel_supply_demand/parser.py`の帳票定義と全国値行の識別処理を更新する。

### 6.2 市区町村第2次速報Excel

現在の実装は次の構造に依存する。

- シート名とA1の表題が参考第5・6・8・11・12表を示す
- 「主な市区町村」の見出しがA列の4～6行目にある
- 市区町村データが7行目以降、所在地がA列にある
- 所在地文字列が都道府県名から始まり、残りを市区町村名として分離できる
- 参考第6・8・11・12表の総数・客室規模別の列位置が固定されている
- 参考第5表の調査対象施設数・回答施設数が客室規模別の列ペアとして並ぶ

表番号、行位置、列位置、所在地表記または客室規模区分が変更された場合は、`src/hotel_supply_demand/municipality/parser.py`を更新する。新しい年月を追加する際は、対象Excelの5表を目視確認し、少なくとも1自治体について総数・外国人・稼働率・施設数を公式表と照合する。

### 6.3 更新時の確認手順

新しい年または月のソースを追加するときは、次を確認する。

1. 公表区分、対象年月、公式配布元が設定と一致する
2. シート名、表題、見出し、行・列配置が既知仕様と一致する
3. parserと品質検証が成功する
4. 都道府県は全国値と代表都道府県、市区町村は代表自治体を原Excelと照合する
5. レコード数、欠損数、掲載自治体数が前回から不自然に変化していない
6. すべて成功した場合だけSQLiteと公開レポートを更新する

## 7. 解釈上の制約

- 都道府県・市区町村統計から個別ホテルのADR、RevPAR、GOP、NOI、担保価値は分からない
- 調査対象施設数は客室数・供給客室数ではなく、施設数の増加だけで供給過多とは判断できない
- 施設タイプ、価格帯、ブランド、商圏、交通条件を調整していない
- 災害、イベント、施設の開閉業などの要因を統計だけで特定できない
- 市区町村値は掲載自治体だけの実数であり、未回収施設を含む市場全体の推計値ではない

実際の担保評価では、対象ホテルの客室数、ADR、RevPAR、GOP、競合施設の開閉業、商圏別需要、契約条件、修繕・設備投資などを追加確認する。
