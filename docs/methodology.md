# 宿泊市場モニタリングの方法論

## 1. 目的と責任範囲

本分析は、ホテル担保の評価・審査・与信管理において、都道府県単位の宿泊市場変化を一次スクリーニングするためのものである。

> SIGNAL → INVEST ではなく、SIGNAL → INVESTIGATE

トリガーは投資判断を自動化せず、担当者が次に確認すべき地域を抽出する。出力では、公式統計から計算した観測事実、都道府県統計から断定できない事項、個別ホテル・商圏について次に確認する事項を分ける。

レポート表面ではアルゴリズムによる総合判定を主役にせず、担当者が全国の地合いと担保物件所在地の時系列を確認できる情報へ限定する。内部の派生指標は分析CSVへ保持する。

## 2. 対象データ

- 統計：観光庁「宿泊旅行統計調査」
- 収録期間：2019～2025年
- 基準月：2025年12月
- 構造比較：2019年12月終了LTM
- 前年比較：2024年12月終了LTMおよび2024年同月
- 粒度：都道府県×月
- 公表区分：年確定値
- 需要：延べ宿泊者数、日本人・外国人延べ宿泊者数
- 稼働：客室稼働率
- 供給の代理変数：施設数

施設数は客室数ではない。100室と500室のホテルがともに1施設となるため、施設数増加を「供給過多」と断定せず、客室数・新規開業・ADR等を追加確認する供給増加警戒シグナルとして扱う。

## 2.1 レポート表示

全国ダッシュボードは次の4項目で構成する。

1. 観光庁公表の全国客室稼働率（月次、直近3年＋2019年）と都道府県別breadth
2. 外国人比率・外国人需要成長率ランキング
3. Seasonal CV・稼働率変動幅・ピーク月／ボトム月による季節変動ランキング
4. 平均稼働率・前年差・外国人比率・施設数の検索／ソート可能な47都道府県一覧

全国客室稼働率は47都道府県の単純平均ではなく、公式Excel第8表の全国値を使用する。画面の年平均はこの月次全国値12個の単純平均である。

breadthは独立表にせず全国市況の直下へ表示する。平均客室稼働率の差が+1.0pt超を上昇、-1.0pt以上+1.0pt以下を横ばい、-1.0pt未満を低下とする。

県別Market SheetはSummary、延べ宿泊者数、客室稼働率に限定する。需要は、直近3年の月次総数を折れ線で比較し、同じ3か年の日本人・外国人年間合計と外国人比率を積み上げ棒＋折れ線で表示する。客室稼働率は直近3年に2019年をReferenceとして重ねる。宿泊施設数は最新月の水準・前年差・2019年差をKPI表示し、月次グラフは設けない。

## 3. 5つの分析軸

| 軸 | 主な指標 | 問い |
|---|---|---|
| Recovery | 2019年同月終了LTM比 | コロナ前水準を回復したか |
| Demand Mix | 外国人比率、外国人LTM YoY | 成長を何が牽引しているか |
| Momentum | 直近3か月YoY、LTM YoY | 足元で加速・減速しているか |
| Supply-Demand | 需要・施設数・稼働率の方向 | 需要と供給のバランスがどう変化したか |
| Seasonality | 稼働率Seasonal CV、稼働率変動幅、需要上位3か月集中度 | 年間を通じた需要がどの程度安定しているか |

時間軸は、直近3か月の短期シグナル、LTM YoYによる基調、2019年同月終了LTM比による構造水準の3段階で読む。LTMは通常の季節変動を平準化するが、イベント、曜日配列、災害などの特殊要因を完全には除去しない。COVID期を含む短い系列に高度な季節調整モデルは適用しない。

## 4. 指標定義

| 指標 | 定義 |
|---|---|
| LTM延べ宿泊者数 | 基準月までの12か月合計 |
| LTM YoY | 当期LTM ÷ 1年前終了LTM − 1 |
| 直近3か月YoY | 直近3か月合計 ÷ 前年同期間合計 − 1 |
| 需要減速 | 直近3か月すべての月で需要YoYが負 |
| 稼働悪化 | 直近3か月すべての月で稼働率前年差が負 |
| 2019年比 | 当期LTM ÷ 2019年同月終了LTM |
| 客室稼働率2019年差 | 当期LTM平均客室稼働率 − 2019年同月終了LTM平均客室稼働率 |
| 外国人比率 | LTM外国人延べ宿泊者数 ÷ LTM延べ宿泊者数 |
| 外国人宿泊者数2019年比 | 当期LTM外国人延べ宿泊者数 ÷ 2019年同月終了LTM外国人延べ宿泊者数 |
| 日本人宿泊者数LTM YoY | 当期LTM日本人延べ宿泊者数 ÷ 1年前終了LTM日本人延べ宿泊者数 − 1 |
| 平均客室稼働率 | LTM12か月の単純平均 |
| 平均施設数 | LTM12か月の単純平均 |

外国人比率は月次比率の平均ではなくLTM合計同士の比率とする。客室稼働率は月別分母を保持していないため単純平均であり、加重平均ではない。

## 5. シグナルと追加調査トリガー

固定幅の閾値を置かず、方向の組み合わせを使用する。

| シグナル | 条件 |
|---|---|
| 需要減速 | 直近3か月すべてで需要YoY < 0 |
| 中期縮小 | 需要LTM YoY < 0 |
| 直近3か月連続稼働悪化 | 直近3か月すべてで稼働率前年差 < 0pt |
| 供給増加警戒 | 施設数LTM YoY > 0 かつ稼働率LTM前年差 < 0pt |
| 需要先行型成長 | 需要LTM YoY > 0、稼働率前年差 > 0、施設数YoY ≤ 0 |
| 供給追随型成長 | 需要LTM YoY > 0、施設数YoY > 0、稼働率維持・上昇 |
| インバウンド主導 | 外国人LTM YoY > 総需要LTM YoY かつ外国人比率上昇 |
| コロナ前水準超過 | 2019年同月終了LTM比 > 100% |

このうち需要減速、中期縮小、直近3か月連続稼働悪化、供給増加警戒を追加調査トリガーとする。成長・回復シグナルも全件保持するが、ウォッチ件数には含めない。

## 6. 全国分布に対する相対位置

固定閾値の代わりに、LTM需要成長率、直近3か月需要成長率、外国人比率、施設数成長率について47都道府県内のpercentileを計算する。

- percentile 75以上：全国上位25%
- percentile 25以下：全国下位25%
- それ以外：全国中位50%

これは市場の良否を示す順位ではなく、同時点の全国分布内での相対位置である。同値はmidrankで処理する。

## 6.1 補足的な市場特性：Seasonality

Seasonalityは市場悪化の判定軸ではなく、市場特性として表示する。

| 指標 | 定義 |
|---|---|
| Seasonal CV | LTM12か月の月次客室稼働率の母標準偏差 ÷ 平均 |
| 客室稼働率変動幅 | LTM12か月の最大客室稼働率 − 最小客室稼働率 |
| 上位3か月集中度 | LTM延べ宿泊者数の多い3か月の合計 ÷ LTM合計 |

それぞれ47都道府県内のpercentileを計算する。Seasonal CVが全国上位25%なら「高季節性」、下位25%なら「低季節性」、上位3か月集中度が全国上位25%なら「ピーク集中型」と表示する。これらは追加調査トリガーや市場の良否判定には使用しない。

## 7. 市場状態分類

単一の総合点を作らず、観測された方向の組み合わせを説明可能な状態名へ変換する。警戒シグナルを成長シグナルより優先表示するが、すべてのシグナルを別項目に保持するため情報は失われない。

## 8. 公表版と前回公表差分

SQLiteの最新版Viewは確定値、第2次速報、第1次速報の順に選択できる。ただし現在は年確定値1版のみで、差し替え前ファイルを保持していない。前回公表差分は算出不能であり、ゼロへ置換しない。

## 9. 解釈上の制約

- 都道府県値から個別ホテルのADR、RevPAR、GOP、NOIは分からない
- 施設数は客室数・供給客室数の代替ではない
- 施設タイプ、価格帯、商圏、ブランド構成を調整していない
- 災害、イベント、交通、開閉業などの要因を統計だけで特定できない
- 2019年単年は正常値や長期均衡を意味しない
- 方向がわずかに正負へ振れた場合も検知するため、数値の大きさと全国相対位置を併読する

ウォッチ対象では、対象ホテルの客室数・ADR・RevPAR・GOP、競合施設の開閉業、商圏別需要、契約条件、修繕・設備投資を追加確認する。
