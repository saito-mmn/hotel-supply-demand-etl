# 市区町村第2次速報 ソース収録状況

## 対象

都道府県年確定値と比較期間をそろえるため、2019年1月から2026年5月までの月次第2次速報89か月を対象とする。原ExcelのURLと提供元識別子を`config/municipality_sources.toml`へ固定した。2019年をコロナ前基準とし、2020～2022年のショックと2023年以降の回復を連続して確認できる。

原則はe-Statの`fileKind=0`原Excelと`statInfId`を採用する。2026年1月だけはe-Stat一覧から原Excelリンクを確認できなかったため、観光庁公式ページが掲載する同月・同公表区分のExcel `002010412.xlsx`を採用する。manifestでは提供元を`mlit`、source IDを`mlit:002010412`として区別し、URL・取得日時・SHA-256を他の月と同様に記録する。

また、2026年1月調査から層化基準が「従業者数」から「客室数」へ変更されている。2025年12月以前との比較では、この制度変更による母集団・掲載状況への影響を考慮する。

公式一覧：<https://www.e-stat.go.jp/stat-search/files?cycle=1&data=1&layout=dataset&metadata=1&page=1&tclass1val=0&toukei=00601020&tstat=000001079597>

観光庁公式ページ：<https://www.mlit.go.jp/kankocho/tokei_hakusyo/shukuhakutokei.html>

レポート一覧には自治体ごとの最新掲載月と掲載月数を表示し、古い掲載値を2026年5月値と誤認しないようにする。市区町村Market Sheetの折れ線は、当該自治体が公式表に掲載された月だけを描画する。

2019年4月には需要表に掲載される一方で利用客室数・稼働率表に掲載されない自治体がある。指標別非表章として、需要を保持し該当指標のみNULLにする。2022年2月の公式表には小数の利用客室数と100%を超える稼働率が含まれる。公式値を丸めたり上限補正したりせず保持し、出典を追跡可能にする。

## 時系列が途切れる原因とMVPの制約

市区町村系列の途切れには、少なくとも次の2種類がある。

### 1. 公式表での非掲載

掲載・回答条件を満たさない月は、自治体そのものが5参考表に掲載されないことがある。代表確認では、徳島県三好市は2019年8月・2026年1月・2026年2月、北海道富良野市は2021年7月・2025年3月・2026年3月だけ原Excelの参考第5・6・8・11・12表に掲載されており、DBの収録月と一致した。この種類の欠測はゼロで補完せず、時系列グラフの線を途切れさせる。

### 2. 公式表の所在地表記変更による系列分断

現在の自治体キーは、原Excelの所在地表記から都道府県名だけを除いた名称に依存している。たとえば同じ倶知安町が、2026年1月以前は`後志総合振興局倶知安町`、2026年2月以降は`虻田郡倶知安町`と表記され、DBでは別自治体・別Market Sheetになっている。これは公式非掲載ではなく、自治体名の名寄せを行っていないことによる系列分断である。

MVPでは、名称から行政区域を推測して自動統合しない。正確な統合には、年月ごとの公式市区町村コードまたはレビュー可能な自治体別名対応表が必要であり、誤結合のリスクに対して実装・検証コストが大きいためである。したがって現行レポートは、原表上の名称単位の掲載状況を表示する。長期推移を利用する際は、名称変更によって系列が分かれていないか原Excelを確認する必要がある。

将来対応する場合は、原表名称とは別に安定した自治体IDを持ち、適用開始・終了年月を含む別名対応表、未対応名称の検知、統合前後の値を照合する回帰テストを整備する。
