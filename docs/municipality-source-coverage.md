# 市区町村第2次速報 ソース収録状況

## 対象

都道府県年確定値と比較期間をそろえるため、2019年1月から2026年5月までの月次第2次速報89か月を対象とする。原ExcelのURLと提供元識別子を`municipality_sources.toml`へ固定した。2019年をコロナ前基準とし、2020～2022年のショックと2023年以降の回復を連続して確認できる。

原則はe-Statの`fileKind=0`原Excelと`statInfId`を採用する。2026年1月だけはe-Stat一覧から原Excelリンクを確認できなかったため、観光庁公式ページが掲載する同月・同公表区分のExcel `002010412.xlsx`を採用する。manifestでは提供元を`mlit`、source IDを`mlit:002010412`として区別し、URL・取得日時・SHA-256を他の月と同様に記録する。

また、2026年1月調査から層化基準が「従業者数」から「客室数」へ変更されている。2025年12月以前との比較では、この制度変更による母集団・掲載状況への影響を考慮する。

公式一覧：<https://www.e-stat.go.jp/stat-search/files?cycle=1&data=1&layout=dataset&metadata=1&page=1&tclass1val=0&toukei=00601020&tstat=000001079597>

観光庁公式ページ：<https://www.mlit.go.jp/kankocho/tokei_hakusyo/shukuhakutokei.html>

- 3観測月以下：28自治体（一覧で注意バッジを表示）

レポート一覧には自治体ごとの最新掲載月と掲載月数を表示し、古い掲載値を2026年5月値と誤認しないようにする。市区町村Market Sheetの折れ線は、当該自治体が公式表に掲載された月だけを描画する。

2019年4月には需要表に掲載される一方で利用客室数・稼働率表に掲載されない自治体がある。指標別非表章として、需要を保持し該当指標のみNULLにする。2022年2月の公式表には小数の利用客室数と100%を超える稼働率が含まれる。公式値を丸めたり上限補正したりせず保持し、出典を追跡可能にする。
